# BAT-DEAD-MAN

Автономный цифровой «аварийный рубильник» (Dead Man's Switch) с криптографическим сейфом, шредером файлов и веб-пультом управления в тёмной неоновой теме.

Если владелец не подтверждает присутствие (чек-ин по PIN-коду) до истечения таймера обратного отсчёта или нажимает кнопку экстренной тревоги (**PANIC**), демон автоматически шифрует все файлы в защищённой директории `vault_safe/`, безвозвратно затирает оригиналы многопроходной перезаписью и опционально блокирует экран ОС.

---

## Инженерные особенности

* **100% Zero-Dependency Python Stdlib:** ни одного стороннего пакета (`pip` и `venv` не нужны). Криптография, многопоточный HTTP-сервер, Drag-and-Drop загрузка файлов и фоновый watchdog реализованы на стандартной библиотеке Python 3 (`hashlib.pbkdf2_hmac`, `hmac`, `secrets`, `ThreadingHTTPServer`).
* **Криптография и контроль целостности:**
  * Хранение PIN-кода через **PBKDF2-HMAC-SHA256** (120 000 итераций + случайная соль) и сравнение за константное время (`hmac.compare_digest`).
  * Потоковое шифрование файлов в формат `.batenc` с проверкой подлинности **Encrypt-then-MAC (HMAC-SHA256)** — при неверном PIN расшифровка блокируется до изменения файлов.
* **Безопасное затирание (Secure Shredding):** перед удалением исходного файла его байты перезаписываются криптостойкими случайными данными (`os.urandom`) и нулями с принудительным сбросом буфера на диск (`os.fsync`).

## Быстрый старт

### macOS
```bash
chmod +x scripts/start_mac.sh
./scripts/start_mac.sh
```

### Windows
Дважды кликните по файлу `scripts/start_windows.bat`.
